# 数据中心架构爆炸图（Data Center Teardown）

一个运行在浏览器里的 3D 爆炸拆解可视化：把数据中心的软硬件基础设施拆成四个层级，逐层爆炸、剖切、点名讲解。

## 四个层级

- **机房**：数据大厅微模块 —— 架空地板、精密空调、UPS、蓄电池、列头配电柜、气体消防、冷通道封闭、桥架与母线槽
- **机柜**：42U 机柜 —— 框架、U 位刻度、PDU、服务器、ToR 交换机、光模块、理线、网孔门
- **服务器**：2U 机架服务器 —— 滑轨、机箱、24 盘位、双路 CPU、内存、散热（鳍片+热管+风扇墙）、GPU、RAID、电源
- **软件**：软件栈金字塔 —— 基础架构软件（OS / 数据库 / 虚拟化 / 容器 / 备份 / 安全 / 运维）→ 中间件 → 行业应用

## 特性

- 7 个行业视图（通用 / 制造 / 金融 / 医疗 / 政务 / 零售 / 能源），切换行业会**整套换装**应用层组件，不只是改文字
- 每个部件标注**国外 5 个 + 国内 5 个主流品牌**（服务器、数据库、操作系统、交换机、存储等 60+ 条目）
- 数据通路动效：每条光带对应真实存在的链路（SAS 背板、PCIe、供电、东西向流量等）
- 开场自动导览、剖切滑杆、线框/网格切换、桌面与移动端自适应

## 技术栈

React + TypeScript + Vite，渲染用 **three.js WebGPURenderer + TSL 节点材质**（不支持 WebGPU 的设备自动回落 WebGL2，代码不分叉），后期链 GTAO → Bloom → SMAA。

## 本地运行

```bash
npm install
npm run dev
npm run build   # 产物在 dist/
```

## 部署

仓库已内置 `vercel.json` 与 `netlify.toml`（构建命令 `npm run build`，输出目录 `dist`），在 Vercel / Netlify 导入本仓库即可自动部署，无需额外配置。
